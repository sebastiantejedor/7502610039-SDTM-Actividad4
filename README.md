# Sistema de Investigación Científica

Modelo de clases en UML (PlantUML) e implementación en Java para el dominio de una universidad que administra investigadores, grupos de investigación, líneas de investigación, proyectos, publicaciones e instituciones colaboradoras.

## Descripción del ejercicio

- Un investigador puede pertenecer a varios grupos y un grupo tiene varios investigadores. Cada participación registra rol, fecha de ingreso y estado.
- Un proyecto involucra a varios investigadores (con rol y porcentaje de dedicación) y a varias instituciones.
- Una publicación tiene varios autores. Por cada uno se registra el orden de autoría y el tipo de contribución.
- Un investigador puede dirigir a otros investigadores en trabajos de formación.
- Algunas líneas de investigación contienen sublíneas.

## Tecnologías

- Java (JDK 11 o superior)
- PlantUML para el diagrama de clases
- Git y GitHub para el control de versiones
